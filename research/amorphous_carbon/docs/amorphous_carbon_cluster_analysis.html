Amorphous carbon cluster analysis¶

This modifier is intended for large amorphous-carbon configurations. It classifies every carbon atom by hybridization state (sp, sp2, or sp3) from its coordination number, groups atoms of a selected hybridization state into connected clusters, and can additionally detect closed primitive rings in the resulting bond graph — letting individual rings be isolated and counted by the number of atoms they contain.

It appears in the Analysis modifier category as Amorphous carbon cluster analysis. A companion modifier, Amorphous carbon cluster tracking, matches clusters found by this modifier between a reference configuration and the current one, to follow how a domain breaks apart over a damage sequence.

Coordination and hybridization¶

The Coordination cutoff parameter is the C–C neighbor cutoff used to determine each atom's coordination number and, from it, its hybridization: 2 neighbors → sp, 3 → sp2, 4 → sp3 (any other coordination is classified as “other”, typically an under- or over-coordinated defect site). A typical choice is the first minimum of the C–C pair distribution function.

The modifier outputs two particle properties from this step:

PropertyMeaning
Carbon CoordinationNumber of neighbors inside the coordination cutoff.
Hybridization0 = other, 1 = sp, 2 = sp2, 3 = sp3.

Connected domains¶

The Connected domains option selects which hybridization state's atoms are clustered: Cluster sp2 atoms or Cluster sp3 atoms. Atoms of the selected state are connected into clusters using the Cluster bond cutoff parameter.

Keep the two cutoffs equal

The bond cutoff defaults to the same value as the coordination cutoff, because a bond good enough to make an atom sp3 should also be a bond along which its cluster (and, see below, its rings) propagate. A bond cutoff shorter than the coordination cutoff discards real bonds and inflates the cluster count; a bond cutoff longer than the coordination cutoff connects clusters along bonds that never counted toward any atom's hybridization, and simultaneously causes the coordination cutoff to under-count neighbors, demoting real sp3 atoms to sp2. On one measured configuration, a 1.9 Å / 2.3 Å mismatch left roughly half of the sp3 population holding a bond outside the graph that defined their own hybridization. Set the two cutoffs equal unless a deliberately stricter or looser connectivity criterion is required, and report the cutoffs alongside any cluster or ring count.

Clusters smaller than Minimum relevant cluster size remain labeled but are excluded from the relevant-cluster count and the clustered fraction.

Clustering a percolating network¶

Connected-component analysis is degenerate for a network above the percolation threshold, which is where sp3-rich amorphous carbon sits: the largest connected component typically holds >90% of the phase regardless of accumulated damage, so its size barely moves as a damage indicator. The Minimum same-phase neighbors parameter restricts clustering to the well-embedded core of the phase: only atoms with at least this many same-phase neighbors are clustered at all. At 0, the whole phase is clustered (degenerate, as above); at 3, only the core is, and the core does lose percolation under damage.

Note

Under a core filter, largest_cluster_fraction and clustered_fraction still divide by the whole phase, not by the atoms admitted by the filter. Use the *_core_* counterparts (largest_cluster_core_fraction, clustered_core_fraction) whenever the filter is active, and never compare a whole-phase fraction between runs that used a different filter setting.

Ring statistics¶

Enabling Detect closed rings (SP/primitive) searches the same-phase bond graph for closed primitive rings and reports how many atoms each one is made of — the quantitative counterpart of isolating individual closed rings by eye when clustering sp3 (or sp2) atoms with the cutoffs tuned so that a ring reads as a clean loop. It is off by default (see performance, below); selecting Color by ring size also enables it automatically.

Ring definition¶

A closed walk is not a useful count by itself: a dense, percolating sp3 network has thousands of closed walks per atom once combinations of smaller rings are allowed — two hexagons fused along a shared edge also form a ten-membered closed walk around their outer boundary, which is not a physically distinct ring. The modifier instead uses the shortest-path (SP) / primitive ring criterion:

D. S. Franzblau, Shortest-path network analysis of the topology of amorphous solids, Phys. Rev. B 44, 4925 (1991).

For every bond (i, j), the modifier finds the shortest alternative path connecting i and j that does not use that bond directly. The resulting cycle is accepted as a ring only if no pair of atoms on it is connected by a strictly shorter path through the rest of the graph — the test that rejects the fused-hexagon example above. Ties among several equally short alternative paths through the same bond are all enumerated and checked independently (capped at 32 candidate paths and 64 tied predecessors per node, to remain tractable in locally symmetric, diamond-like regions; this cap is not expected to bind on a genuinely amorphous network).

Periodic boundary conditions

A candidate ring is only accepted if it closes in real, unwrapped space: the net periodic-image shift accumulated around the loop must be exactly zero, using the same integer bookkeeping the percolation test already uses for clusters. This prevents a path that merely wraps around the periodic cell — a percolation loop, not a molecule — from being reported as a ring. In practice this never binds for realistic cell sizes: a ring of up to Maximum ring size to search atoms spans at most a few bond lengths, far below a typical simulation cell edge length.

Parameters¶

ParameterRoleDefault
Maximum ring size to search Bounds the shortest-path search depth; the main cost control. Real rings in amorphous carbon are almost always well under 10 atoms.8
Minimum ring size to search Filters out reported rings smaller than this size after detection (e.g. to exclude triangles). Cannot go below 3, the smallest ring a simple graph can contain; 1- and 2-atom “rings” never occur. 3

Raising Minimum ring size to search does not search for a larger ring through the same bond in place of a discarded small one — each bond contributes at most its own shortest primitive ring (or tied set of rings), consistent with the SP criterion above.

Color by ring size maps Ring Size to a sequential ramp (light = small rings, dark = large rings); atoms outside any found ring are shown in a neutral graphite tone.

Performance¶

The search runs a depth-bounded breadth-first search from every bond in the selected phase, so cost scales with the number of bonds and with Maximum ring size to search. Measured on a 473,344-atom configuration: about 10 seconds in addition to the existing cluster analysis (which by itself takes about 10 seconds), with the default maximum ring size of 8.

Validation

No independent reference implementation exists for this criterion, so correctness was checked against physical expectation rather than a line-by-line comparison. On the least-damaged configuration available (most diamond-like), the sp3 primitive rings averaged 6.004 atoms — matching the ideal diamond lattice, which is composed entirely of six-membered (chair-conformation) rings, to three significant figures. Under accumulated damage, the mean ring size decreased as five-membered defect rings appeared, and the sp2 phase (fragmented into small clusters) yielded far fewer rings than the percolating sp3 matrix — both in the physically expected direction. Raising Minimum ring size to search from 3 to 6 on one configuration removed rings and raised the mean size monotonically, as a size floor must.

Rings are not the same as visually distinguishable cluster shape

Before this per-bond search existed, the only way to spot a “ring” was by eye, from small connected-component clusters that happened to look loop-shaped — which depends on how fragmented the network is, not on whether real closed cycles exist. A configuration where nearly the entire phase sits in one giant cluster has no small-cluster substructure left to look at, even though it may contain more real primitive rings than a more fragmented, more damaged configuration where small ring-shaped clusters are easy to see. Always read ring counts from Ring Size / ring_count_total, never from how many ring-like shapes are visible in a cluster-colored render.

Visualization¶

The Particle coloring option can color particles by hybridization, cluster identifier, cluster size, same-phase coordination, or (see above) ring size, or leave existing colors untouched.

Global attributes

All attributes are reported under the AmorphousCarbon.* namespace: composition counts and percentages for each hybridization state, cluster statistics (count, largest cluster size and fraction, percolation flag, radius of gyration), the core-filter counterparts described above, the two cutoffs used, and — when ring analysis is enabled — the ring statistics listed in the table above.

Batch mode

The companion command-line entry point --carbon-track runs this modifier (and, downstream, Amorphous carbon cluster tracking) over a whole trajectory without opening the GUI, writing one CSV row per frame. Ring analysis is controlled by --carbon-track-rings, --carbon-track-max-ring-size, and --carbon-track-min-ring-size.
